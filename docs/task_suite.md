# 共享桌面的 25 个采集任务

去掉碗之后，盘子是唯一的容器。桌上 16 个物体都至少进入一条任务，7 种操作模式都有覆盖。1、13、24 已经采过。

22 右手夹起锤子敲扑克牌，23 左手夹起扫描仪对准黄垫。锤子和扫描仪只在这两条任务里改成可动物体，其它任务仍把它们当固定底座。25 把滚筒抬离桌面。14 和 15 的旋钮没有夹取点，要另写侧面拨动。

8、11、12 原先是左手放进盘子。左手够不到盘子内部，所以改成放到垫上。放进容器仍由 9、10 覆盖，罐头仍出现在 12。

## 包含的模式

| 模式 | 任务 | 结束时多出来的状态 |
| --- | --- | --- |
| 放到平面 | 1–8、11、12、22、23、25 | 夹爪张开，物体落在垫上或另一个方块上。22 结束时锤子仍被右手握住，锤头落在扑克牌上。23 结束时扫描仪仍被左手握住，并对准黄垫 |
| 放进容器 | 9、10 | 物体落到盘子内部，下降时越过边沿 |
| 下压 | 13、24 | 按钮关节至少下降 3 mm。铃铛用闭合夹爪按顶部 |
| 转动 | 14、15 | 旋钮绕竖直轴相对初始角变化，底座不动 |
| 推移 | 16、17 | 物体贴着桌面平移，高度留在桌面上 |
| 交接 | 18、19 | 同一个物体从一只手交到另一只手，结束时接住的那只夹爪闭合 |
| 双手同时 | 20、21 | 两只手在同一阶段各抬起一个物体 |
